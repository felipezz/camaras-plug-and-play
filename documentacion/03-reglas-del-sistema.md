# Reglas del sistema

## 1. Cada puerto corresponde a una cámara específica

```text
Puerto 1 del SW-J101-J102 = Jaula 101 - Cámara A
```

## 2. Todas las cámaras deben prepararse igual

- [ ] DHCP habilitado.
- [ ] ONVIF habilitado.
- [ ] Visualización disponible para el NVR sin contraseña adicional.
- [ ] Configuración estándar revisada.

## 3. Los switches se configuran antes de instalarse

Deben salir nombrados, con IP, configurados y rotulados.

## 4. Los equipos y puertos deben quedar rotulados

```text
SW-J101-J102
J101-A
J101-B
J102-A
J102-B
```

## 5. Toda instalación debe probarse reemplazando una cámara

El mismo canal debe recuperar la imagen sin modificar el NVR.
